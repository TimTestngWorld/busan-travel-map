# Beta 2.9 旅遊地圖｜App Dashboard・Smart Labels

本版以 Beta 2.8 的「公版核心 + Local First」為基準，集中改善第一次使用的直覺性與手機閱讀體驗。

## 本版完成

- 新增 **App 首頁儀表板**：打開先選「我的行程／景點地圖／找景點／我的景點」等功能，不再一進站就面對滿版地圖。
- 儀表板顯示目前景點數、已排行程數、想去、已去等摘要。
- 地圖改成 **智慧標籤**，預設 `自動`：
  - 縮小：只顯示景點圖釘，避免 81 個標籤塞滿畫面。
  - 中段縮放：優先顯示已排 Day／想去／已去的景點。
  - 放大：逐步顯示更多景點；更近時會帶景點名稱。
  - `更多 → 景點標籤` 可循環切換 `自動 → 全部 → 關閉`。
- 點中的景點會保留強調標記與名稱，即使標籤模式為關閉也不會失去目前焦點。
- 景點詳情、結果清單、Day 行程、編輯表單與操作按鈕的字體全面放大。
- 頂端工具列精簡；機場、換錢所、定位、底圖、PNG 等次要功能集中到 Dashboard / 更多。
- 新增 `⌂ 首頁`，從地圖可隨時回儀表板。
- 首頁預留 **旅行分帳** 與 **分享旅行** 入口，目前會提示 Beta 2.10 上線，不會寫入假資料。
- Beta 2.8 的 IndexedDB、localStorage 相容備援、自訂景點、Supabase Places Proxy、Google Places 實景照片全部保留。

## GitHub 部署

請把本資料夾內容放在 GitHub Pages repository 根目錄。`data/` 不可漏傳。

`app-config.js` 沿用目前已部署的 Supabase Project URL / Publishable Key；Google API Key 仍只存在 Supabase Secret。

## 本版刻意還沒做

- 分帳／匯率：Beta 2.10。
- Day 行程圖片、旅行分享碼、手機 Share Sheet：Beta 2.10。
- Travel Map Manager：Beta 2.11。
- PWA 安裝／離線：Beta 3.0。

## 建議測試重點

1. 第一次打開是否能立即理解首頁六個功能。
2. 進地圖後，預設縮放是否不再滿版標籤。
3. `更多 → 景點標籤` 三種模式是否符合使用習慣。
4. 手機點景點後，名稱、地址、備註、按鈕是否足夠大。
5. 原 Beta 2.8 的 Day／狀態／備註／自訂景點是否完整保留。
